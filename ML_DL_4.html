01Линейная регрессия

Базовая модель ML: предсказываем число как взвешенную сумму признаков. Фундамент, на котором стоит всё остальное.

💡 Интуиция

Проводим прямую (или гиперплоскость) сквозь облако точек так, чтобы сумма квадратов ошибок по вертикали была минимальна. Квадрат штрафует большие промахи сильнее и даёт гладкую функцию с единственным минимумом.

📐 Модель и MSE
$$\hat{y} = w^\top x + b, \quad \mathrm{MSE}=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2$$

Каждый вес \(w_j\) — вклад j-го признака в предсказание (в единицах целевой переменной).

⚙️ Градиентный спуск
$$\nabla_w \mathrm{MSE} = -\frac{2}{n}X^\top(y-Xw)$$

\(w \leftarrow w - \eta \nabla_w\). Идём антиградиенту — направление наискорейшего убывания потерь.

🎯 Аналитическое решение
$$w^* = (X^\top X)^{-1}X^\top y$$

Нормальные уравнения. Работает мгновенно для малых данных. При \(p>n\) или мультиколлинеарности матрица необратима → Ridge.

🛡️ Регуляризация: Ridge / Lasso / ElasticNet

Большие веса = переобучение. Регуляризация добавляет штраф за величину весов:

$$\text{Ridge (L2): }+\lambda\|w\|_2^2 \qquad \text{Lasso (L1): }+\lambda\|w\|_1 \qquad \text{ElasticNet: }\lambda_1\|w\|_1+\lambda_2\|w\|_2^2$$
Ridge (L2)

Сжимает все веса равномерно, но не обнуляет. Штраф — круг. Решение = касание эллипса MSE с кругом. Стабилизирует при коррелированных признаках.

Lasso (L1)

Штраф — ромб с углами на осях. Эллипс касается угла ⇒ часть весов ровно 0. Встроенный отбор признаков!

ElasticNet

Компромисс: L1 даёт разреженность, L2 стабилизирует. Параметр l1_ratio управляет балансом.

🎮 Демо: Градиентный спуск + Геометрия регуляризации

Слева: GD вживую. Справа: Ridge (круг) vs Lasso (ромб)
Геометрия: жёлтая = OLS, зелёная = регуляризованное решение

🐍 Python

from sklearn.linear_model import LinearRegression, Ridge, Lasso, ElasticNet
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import mean_squared_error, r2_score

sc = StandardScaler().fit(X_tr)          # ОБЯЗАТЕЛЬНО для Ridge/Lasso!
model = Ridge(alpha=1.0).fit(sc.transform(X_tr), y_tr)
pred = model.predict(sc.transform(X_te))

print("RMSE:", mean_squared_error(y_te, pred, squared=False))
print("R²  :", r2_score(y_te, pred))
print("w   :", model.coef_)             # Lasso обнулит слабые признаки

🔧 Параметры модели

alpha (λ)
Сила регуляризации. 0 = обычная регрессия, больше → сильнее сжатие весов. Подбирают через CV.
l1_ratio (ElasticNet)
Доля L1-штрафа. 1.0 = чистый Lasso, 0.0 = чистый Ridge, 0.5 = баланс.
fit_intercept
Считать ли свободный член b отдельно (обычно True).
⚠️ Ограничения и опасности
  • Линейность: не ловит нелинейные зависимости без полиномиальных признаков.
  • Мультиколлинеарность: скоррелированные признаки делают веса нестабильными → используйте Ridge или PCA.
  • Выбросы: MSE чувствительна к выбросам → RobustRegressor или Huber loss.
  • Масштаб: перед Lasso/Ridge обязательно стандартизируйте признаки!
🏙️ Кейс: прогноз стоимости квартир

12 признаков, Lasso обнулил 4 малоинформативных, R² = 0.81. Коэффициенты интерпретируемы: +9 800 ₽/м² в центре, −420 ₽/м² за год возраста. Бизнес понимает модель → доверие выше, чем к чёрному ящику.

02Полиномиальная регрессия · SVR

Как моделировать нелинейность, оставаясь «линейной» моделью, и как SVR использует ε-трубку.

💡 Полиномы

Добавляем степени: \(x\to(x,x^2,x^3)\). Модель линейна по параметрам, но кривая в исходном пространстве. Степень — главный гиперпараметр: мала → недообучение, велика → переобучение.

📐 SVR (ε-Support Vector Regression)
$$\min\tfrac12\|w\|^2+C\sum(\xi_i+\xi_i^*)$$

Ошибки внутри трубки ±ε не штрафуются. Обучаются только точки на границе (опорные). Ядра дают нелинейность.

🎮 Демо: Переобучение полиномов

🐍 Python

from sklearn.preprocessing import PolynomialFeatures
from sklearn.pipeline import make_pipeline
from sklearn.svm import SVR

poly = make_pipeline(PolynomialFeatures(degree=3), Ridge())
svr  = SVR(kernel="rbf", C=10, epsilon=0.1, gamma="scale")

🔧 Параметры SVR

C
Жёсткость: большое C → узкая трубка, меньше ошибок на обучении, риск переобучения.
epsilon (ε)
Ширина трубки «безразличия». Больше ε → более гладкая модель, меньше опорных векторов.
kernel
linear, rbf, poly. RBF — универсальный выбор по умолчанию.
gamma
Обратный радиус влияния RBF-ядра. Большое → каждый образец влияет локально.
⚠️ Ограничения
  • Полиномы высокой степени численно нестабильны → всегда нормализуйте x в [-1, 1].
  • SVR масштабируется плохо (\(O(n^2..n^3)\)) → для n>10k используйте SGDRegressor или Nyström.
  • SVR чувствителен к масштабу → StandardScaler обязателен.

03Логистическая регрессия

Несмотря на название — классификатор. Возвращает вероятность класса. Рабочая лошадка продакшена.

💡 Сигмоида
$$\sigma(z)=\frac{1}{1+e^{-z}},\quad z=w^\top x+b$$

Сжимает \((-\infty,+\infty)\) в \((0,1)\). Порог 0.5 → класс 1. Можно двигать порог под задачу.

📐 Cross-Entropy Loss
$$L=-\frac{1}{n}\sum[y_i\ln p_i+(1-y_i)\ln(1-p_i)]$$

Градиент красивый: \(\nabla_w L = \frac{1}{n}X^\top(\sigma(Xw)-y)\). MSE здесь дала бы плоские градиенты.

🎮 Демо: Граница решения + обучение

💡 Кликай по холсту — добавить точку. Shift+Click = класс 0.

🐍 Python

from sklearn.linear_model import LogisticRegression
clf = LogisticRegression(C=1.0, penalty="l2", class_weight="balanced", max_iter=1000)
clf.fit(X_tr, y_tr)
p = clf.predict_proba(X_te)[:, 1]     # вероятности!

🔧 Параметры

C
Обратная сила регуляризации (C=1/λ). Меньше C → сильнее регуляризация.
penalty
l1, l2, elasticnet, none.
class_weight
"balanced" автоматически компенсирует дисбаланс классов.
solver
lbfgs (дефолт), saga (для l1 и больших данных), liblinear (малые данные).
⚠️ Ограничения
  • Линейная граница → не справится с XOR без признаков-взаимодействий.
  • Предполагает линейную разделимость в log-odds пространстве.
  • Мультиколлинеарность делает коэффициенты нестабильными (но предсказания остаются ок).
💳 Кейс: Антифрод

0.4% мошеннических транзакций. LogReg + class_weight="balanced" + порог 0.25: recall 0.86, precision 0.31. Топ-факторы: ночное время ×2.4, смена устройства ×3.1. Модель объяснима для регулятора.

04SVM — Метод опорных векторов

Разделяем классы с максимальным зазором. Решение определяется несколькими «опорными» точками.

💡 Максимальный отступ
$$\text{margin}=\frac{2}{\|w\|}\Rightarrow\min\tfrac12\|w\|^2$$

Выпуклая задача → единственный глобальный минимум. Опорные векторы — точки на границах полосы.

🔩 Soft Margin + Ядра
$$\min\tfrac12\|w\|^2+C\sum\xi_i,\quad K(x,x')=e^{-\gamma\|x-x'\|^2}$$

C контролирует компромисс зазор/ошибки. Ядерный трюк: нелинейное разделение без явного φ(x).

🎮 Демо: Зазор и параметр C

🐍 Python

from sklearn.svm import SVC
from sklearn.preprocessing import StandardScaler
pipe = make_pipeline(StandardScaler(), SVC(kernel="rbf", C=10, gamma="scale"))
# ВСЕГДА стандартизуй перед SVM!

🔧 Параметры

C
Большое C → жёсткий зазор, меньше ошибок на train, риск переобучения. Малое C → широкий зазор, робастнее.
kernel
linear (тексты, высокие размерности), rbf (универсал), poly.
gamma
Для RBF: "scale" = 1/(n_features·var), "auto" = 1/n_features.
⚠️ Ограничения
  • Плохо масштабируется: \(O(n^2..n^3)\) → для n>50k используйте LinearSVC или SGDClassifier.
  • Не выдаёт вероятности «из коробки» (нужен Platt scaling, probability=True — медленно).
  • Чувствителен к масштабу и выбросам при большом C.
  • Не работает с категориальными признаками напрямую.
🧬 Кейс: Классификация текстов

TF-IDF 40 000 признаков, 20 000 документов. LinearSVM (C=1) → accuracy 0.91 за секунды. Классика высокоразмерных разреженных данных.

05Наивный Байес

Теорема Байеса + предположение о независимости признаков. Мгновенное обучение, силён на текстах.

📐 Теорема Байеса
$$P(y|x)\propto P(y)\prod_j P(x_j|y)$$

«Наивность» = независимость признаков при данном классе. Неправда, но для ранжирования работает!

Варианты

GaussianNB — непрерывные признаки (нормальное распределение).
MultinomialNB — частоты/счётчики (тексты).
BernoulliNB — бинарные признаки.
Сглаживание Лапласа (alpha) спасает от нулевых вероятностей.

🎮 Демо: Два гауссиана и граница Байеса

🐍 Python

from sklearn.naive_bayes import GaussianNB, MultinomialNB
gnb = GaussianNB().fit(X_tr, y_tr)
mnb = MultinomialNB(alpha=1.0).fit(X_counts, y)  # alpha = сглаживание

🔧 Параметры

alpha (Multinomial/Bernoulli)
Сглаживание Лапласа. 1.0 = стандарт, 0 = без сглаживания (риск нулей).
var_smoothing (Gaussian)
Добавляется к дисперсии для численной стабильности.
⚠️ Ограничения
  • Предположение независимости почти никогда не выполняется → калибровка вероятностей плохая.
  • GaussianNB предполагает нормальность → если признаки скошены, преобразуйте или используйте Kernel NB.
  • Плохо работает с коррелированными признаками (двойной учёт информации).
📧 Кейс: Спам-фильтр

MultinomialNB на мешке слов: обучение за 0.3 сек на 50k писмах, precision 0.97. Базовый фильтр в стекинге с логрегом.

06k-NN — Метод ближайших соседей

Модель = сами данные. Ленивое обучение: запоминаем train, предсказываем голосованием k соседей.

💡 Алгоритм
$$d_p(a,b)=\Big(\sum_j|a_j-b_j|^p\Big)^{1/p}$$

k=1 → рваная граница, шум. Большое k → гладко, но размывает. Масштабирование обязательно!

⚠️ Проклятие размерности

В высоких размерностях все точки равноудалены → «ближайшие» теряют смысл. Перед k-NN: PCA или отбор признаков.

🎮 Демо: k-NN с картой решений

🐍 Python

from sklearn.neighbors import KNeighborsClassifier
knn = KNeighborsClassifier(n_neighbors=7, weights="distance", metric="minkowski", p=2)
# ОБЯЗАТЕЛЬНО: StandardScaler перед fit!

🔧 Параметры

n_neighbors (k)
Главный гиперпараметр. Нечётное для бинарной классификации. Подбирают через CV.
weights
"uniform" — все равны, "distance" — ближние весят больше (рекомендуется).
metric / p
p=2 евклидова, p=1 манхэттен. Для текстов — косинусная.
algorithm
"auto" выбирает между ball_tree, kd_tree и brute.
⚠️ Ограничения
  • Медленное предсказание: \(O(n \cdot d)\) на один запрос. KD-tree помогает, но не в высоких размерностях.
  • Хранит весь train в памяти.
  • Категориальные признаки требуют специального расстояния или one-hot + масштабирования.
  • Чувствителен к нерелевантным признакам → отбор обязателен.

07Деревья решений

Игра в «20 вопросов»: оси-параллельные разбиения. Интерпретируемы, не требуют масштабирования, ловят нелинейности.

📐 Критерии нечистоты
$$\text{Gini}=1-\sum p_k^2\qquad H=-\sum p_k\log_2 p_k$$

Оба минимальны (0) в чистом листе. Жадный выбор сплита по максимальному Gain.

⚠️ Переобучение

Без ограничений дерево запомнит всю выборку. Лечат: max_depth, min_samples_leaf, pruning… или ансамбли.

🎮 Демо: Глубина = переобучение

🐍 Python

from sklearn.tree import DecisionTreeClassifier
tree = DecisionTreeClassifier(max_depth=4, min_samples_leaf=5, criterion="gini")
tree.fit(X_tr, y_tr)
print(tree.feature_importances_)  # важность признаков

🔧 Параметры

max_depth
Максимальная глубина. Главный регулятор сложности. 3–8 для бустинга, 5–15 для одиночного дерева.
min_samples_leaf
Минимум объектов в листе. Увеличение → регуляризация.
min_samples_split
Минимум объектов для попытки сплита.
criterion
"gini" (быстрее) или "entropy". Результаты почти идентичны.
max_features
Число признаков для рассмотрения в каждом сплите. "sqrt" для RF.
⚠️ Ограничения
  • Нестабильны: малое изменение данных → совсем другое дерево. Лечится ансамблями.
  • Только оси-параллельные границы → диагональные разделяются ступеньками.
  • Склонны к переобучению без регуляризации.
  • Не экстраполируют за пределы обучающих данных (регрессия).

08Ансамбли: RF · Бустинг · Стекинг

Много слабых моделей вместе бьют одну сильную. Чемпионы табличных данных.

👜 Бэггинг → Random Forest
$$\mathrm{Var}(\tfrac{1}{B}\sum f_b)=\rho\sigma^2+\frac{1-\rho}{B}\sigma^2$$

Бутстрэп + случайные признаки → декорреляция деревьев → усреднение гасит дисперсию.

🚀 Бустинг → Gradient Boosting
$$F_m=F_{m-1}+\nu\,h_m,\quad h_m\approx(y-F_{m-1})$$

Каждое дерево учит остатки предыдущих. Маленький ν + много деревьев = плавная точная модель.

🏆 XGBoost / LightGBM / CatBoost

XGBoost: 2-й порядок Тейлора + регуляризация. LightGBM: гистограммы + leaf-wise. CatBoost: ordered encoding для категорий.

🎮 Демо: Random Forest + Gradient Boosting

Random Forest: число деревьев → гладкость границы
Gradient Boosting: стадии + кривая обучения

🐍 Python

from sklearn.ensemble import RandomForestClassifier
import xgboost as xgb
import lightgbm as lgb
from catboost import CatBoostClassifier

rf = RandomForestClassifier(n_estimators=300, max_features="sqrt", oob_score=True)
xg = xgb.XGBClassifier(n_estimators=500, learning_rate=0.05, max_depth=6)
cb = CatBoostClassifier(iterations=500, cat_features=cat_idx, verbose=0)

🔧 Ключевые параметры бустинга

n_estimators
Число деревьев. Больше → лучше, но медленнее. Ранняя остановка по eval_set обязательна!
learning_rate (ν)
Шаг. Меньше → плавнее, нужно больше деревьев. Типично 0.01–0.1.
max_depth
Глубина деревьев. 3–8 для бустинга. Больше → переобучение.
subsample / colsample_bytree
Доля объектов/признаков на дерево. Стохастичность = регуляризация.
reg_lambda / reg_alpha
L2/L1 регуляризация листьев (XGBoost).
⚠️ Ограничения
  • RF: плохо экстраполирует, тяжёл по памяти (хранит все деревья).
  • Бустинг: переобучается при слишком большом числе стадий → early stopping!
  • Бустинг: последовательное обучение → сложно параллелить (кроме LightGBM).
  • Все ансамбли: менее интерпретируемы, чем одно дерево (но есть SHAP).

09Кластеризация: K-Means · DBSCAN · Иерархическая

Ищем скрытую структуру без ответов: сегменты, аномалии, сжатие.

🎯 K-Means
$$\min\sum_{c}\sum_{x\in c}\|x-\mu_c\|^2$$

EM-цикл: назначить → пересчитать. K-means++ для инициализации. Строит «круглые» кластеры.

🌫️ DBSCAN

Кластер = область плотности. ε-радиус + minPts. Ловит любую форму, находит шум. Не любит переменную плотность.

🌲 Иерархическая

Агломеративное слияние. Linkage: single/complete/average/Ward. Дендрограмма → режь на любой высоте. \(O(n^2)\) память.

🎮 Демо: K-Means + DBSCAN

K-Means: шаг за шагом + локоть
DBSCAN: полумесяцы + шум

🐍 Python

from sklearn.cluster import KMeans, DBSCAN
from sklearn.metrics import silhouette_score

km = KMeans(n_clusters=5, n_init=10).fit(Xs)
db = DBSCAN(eps=0.18, min_samples=5).fit(Xs)
print(silhouette_score(Xs, km.labels_))

🔧 Параметры

n_clusters (K-Means)
Подбирают по локтю inertia или silhouette score.
eps (DBSCAN)
Радиус окрестности. Берут из k-distance графика (расстояние до k-го соседа).
min_samples (DBSCAN)
Минимум соседей для core-точки. Обычно 2×dim.
⚠️ Ограничения
  • K-Means: только выпуклые кластеры, чувствителен к инициализации, требует задания k.
  • DBSCAN: плохо с переменной плотностью, чувствителен к eps, \(O(n^2)\) без индексов.
  • Иерархическая: \(O(n^2)\) память → максимум ~10k точек.
  • Все: нет «правильного» ответа → валидация предметная, не математическая.

10PCA · t-SNE · UMAP

Сжимаем 1000 признаков в 2–50, сохраняя главное. Визуализация многомерных данных.

📐 PCA
$$Cv_i=\lambda_i v_i,\quad\text{explained}=\frac{\lambda_i}{\sum\lambda}$$

Линейное сжатие. Собственные векторы ковариационной матрицы = направления макс. дисперсии. Есть transform.

🌌 t-SNE
$$\min KL(P\|Q),\quad q_{ij}\propto(1+\|y_i-y_j\|^2)^{-1}$$

Нелинейная визуализация соседей. Perplexity ≈ эффективное число соседей. НЕ имеет transform. Только для картинок!

🕸️ UMAP

kNN-граф + топология. Быстрее t-SNE, сохраняет глобальную структуру, умеет transform. Стандарт выбора для визуализации.

🎮 Демо: PCA + t-SNE в браузере

PCA: стрелки = главные компоненты
t-SNE: два кольца, 400 итераций прямо здесь

🐍 Python

from sklearn.decomposition import PCA
from sklearn.manifold import TSNE
import umap

pca = PCA(n_components=0.95).fit_transform(X_scaled)
emb = TSNE(perplexity=30, init="pca").fit_transform(X_scaled)
emb2 = umap.UMAP(n_neighbors=15, min_dist=0.1).fit_transform(X_scaled)
⚠️ Ограничения
  • PCA: только линейные структуры. Для нелинейных → kernel PCA или UMAP.
  • t-SNE: нет transform, стохастичен (разные запуски = разные картинки), искажает глобальную геометрию.
  • UMAP: гиперпараметры n_neighbors/min_dist сильно влияют на результат.
  • ВСЕГДА стандартизируй перед снижением размерности!

11Ассоциативные правила · Apriori

«Анализ корзин»: что покупают вместе. Support, Confidence, Lift.

📐 Три метрики
$$\text{sup}(A)=\frac{\#(A)}{N},\quad\text{conf}(A{\Rightarrow}B)=\frac{\text{sup}(A\cup B)}{\text{sup}(A)},\quad\text{lift}=\frac{\text{conf}}{\text{sup}(B)}$$

Lift > 1 = реальная связь. Lift ≈ 1 = независимы.

✂️ Антимонотонность

Подмножество частого набора тоже частое → отсечение на порядки ускоряет перебор.

🎮 Демо: Редактируй корзины

Частые наборы
Правила (по lift)
⚠️ Ограничения
  • Экспоненциальная сложность при большом числе товаров → только для умеренных наборов.
  • Confidence может быть обманчива → всегда смотри lift.
  • Не учитывает временную динамику.

12Обучение с подкреплением: Q-Learning · DQN · PPO

Нет ответов — есть награда. Агент учится политике через пробу и ошибку.

🔁 Bellman + Q-Learning
$$Q(s,a)\leftarrow Q(s,a)+\alpha[r+\gamma\max_{a'}Q(s',a')-Q(s,a)]$$

Табличный метод. γ — дисконт, α — скорость, ε — исследование. Off-policy.

🎮 DQN

Q-функция ≈ CNN. Replay buffer (убирает корреляции) + Target network (стабильность цели).

✂️ PPO (Actor-Critic)
$$L=\mathbb{E}\big[\min(\tfrac{\pi_\theta}{\pi_{old}}A,\;\mathrm{clip}(\tfrac{\pi_\theta}{\pi_{old}},1\pm\varepsilon)A)\big]$$

Клип защищает от разрушительных обновлений. Стандарт для RLHF и робототехники.

🎮 Демо: Q-Learning в лабиринте

🔧 Параметры Q-Learning

γ (discount)
0 → живи одним днём. 0.99 → дальновидный стратег.
α (learning rate)
Скорость обновления Q. Слишком большой → нестабильность.
ε (exploration)
Доля случайных ходов. Затухает со временем (ε-decay).
⚠️ Ограничения
  • Табличный Q-Learning: только для маленьких пространств состояний.
  • DQN: нестабилен, требует тщательной настройки replay buffer и target network.
  • PPO: чувствителен к нормализации наград и наблюдений.
  • RL в целом: требует миллионов шагов, reward shaping — искусство, воспроизводимость низкая.

13Backpropagation · Оптимизаторы · Активации

Три кита DL: как считать градиенты, как идти, чем изгибать.

⛓️ Chain Rule = Backprop
$$\frac{\partial L}{\partial w}=\frac{\partial L}{\partial a}\cdot\frac{\partial a}{\partial z}\cdot\frac{\partial z}{\partial w}$$

Прямой ход: значения слева→направо. Обратный: градиенты справа→налево. Сложность ≈ 2× forward.

🏃 SGD → Momentum → Adam
$$\text{Adam: }m=\beta_1 m+(1{-}\beta_1)g,\;v=\beta_2 v+(1{-}\beta_2)g^2$$

Momentum = импульс. Adam = адаптивный шаг на параметр. Дефолт: β₁=0.9, β₂=0.999.

🎚️ Активации

ReLU: дёшево, но мёртвые нейроны. GELU: трансформеры. Sigmoid/Tanh: гейты. Softmax: классификация.

🎮 Демо: Backprop + Гонка оптимизаторов

Один нейрон: forward → loss → grad → step
SGD vs Momentum vs Adam на функции Била

🐍 Python

model = Net().to("cuda")
crit = nn.CrossEntropyLoss()              # log-softmax ВНУТРИ!
opt  = torch.optim.AdamW(model.parameters(), lr=3e-4, weight_decay=0.01)

for x, y in loader:
    opt.zero_grad()
    loss = crit(model(x), y)              # forward
    loss.backward()                       # ← весь backprop одной строкой
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
    opt.step()
⚠️ Опасности
  • Vanishing gradient: sigmoid/tanh в глубоких сетях → градиенты затухают. Решение: ReLU, residual connections, BatchNorm.
  • Exploding gradient: clip_grad_norm_ обязателен для RNN.
  • Dead ReLU: нейроны навсегда замолкают. Решение: LeakyReLU, правильная инициализация (He).
  • Softmax + CE раздельно: численная нестабильность! Всегда используй nn.CrossEntropyLoss (log-sum-exp trick).

14CNN — Свёрточные сети

Признаки изображений локальны и повторяются. Ядро скользит → карта признаков. Разделение весов = тысячи раз меньше параметров.

🔍 Свёртка
$$(I*K)[i,j]=\sum_{u,v}K[u,v]\,I[i{+}u,j{+}v]$$

3×3×3 ядро = 27 весов на ВСЁ изображение. Output size: \(W_{out}=(W-K+2P)/S+1\).

📏 Pooling + Иерархия

MaxPool 2×2 → сжатие + сдвиг-инвариантность. Слой 1: края → 2-3: текстуры → глубже: части объектов.

🎮 Демо: Свёртка руками

🐍 Python

class CNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 32, 3, padding=1), nn.BatchNorm2d(32), nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(32, 64, 3, padding=1), nn.ReLU(), nn.AdaptiveAvgPool2d(1))
        self.head = nn.Sequential(nn.Flatten(), nn.Dropout(0.3), nn.Linear(64, 10))
⚠️ Ограничения
  • Требует много размеченных данных (или transfer learning).
  • Не инвариантна к поворотам (только к сдвигам) → аугментации обязательны.
  • Интерпретируемость низкая → Grad-CAM, saliency maps для понимания.
  • Adversarial attacks: малозаметные возмущения ломают предсказания.

15RNN · LSTM · GRU

Сети с памятью: скрытое состояние передаётся от шага к шагу. Текст, звук, временные ряды.

🔁 RNN + Vanishing Gradient
$$h_t=\tanh(W_{xh}x_t+W_{hh}h_{t-1}+b)$$

Произведение якобианов → затухание/взрыв. Долгие зависимости не выучить.

🚪 LSTM
$$C_t=f_t\odot C_{t-1}+i_t\odot\tanh(\cdot),\quad h_t=o_t\odot\tanh(C_t)$$

Forget/Input/Output gates + аддитивная клеточная память = градиент течёт без затухания.

🎮 Демо: LSTM Cell Memory

⚠️ Ограничения
  • Последовательная обработка → нельзя параллелить (медленнее трансформеров на GPU).
  • Длинные зависимости всё ещё трудны (>500 шагов) → трансформеры вытеснили RNN в NLP.
  • BPTT: memory растёт линейно с длиной последовательности → truncated BPTT.
  • Временные ряды: часто проигрывают градиентному бустингу на табличных фичах.

16Трансформеры · LLM

«Attention is All You Need». Каждый токен видит все остальные. Параллелизм + дальние зависимости.

🔦 Self-Attention
$$\mathrm{Attn}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

Query/Key/Value. √d_k предотвращает насыщение softmax. Multi-head = несколько «взглядов».

📚 Encoder (BERT) vs Decoder (GPT)

BERT: bidirectional, masked-LM. Понимание. GPT: causal mask, next-token. Генерация. Масштабирование рождает эмерджентные способности.

🎮 Демо: Attention Heatmap

🐍 Python

from transformers import pipeline
clf = pipeline("sentiment-analysis", model="blanchefort/rubert-base-cased-sentiment")
print(clf("Отличный сервис!"))

# Мини-attention вручную
import torch.nn.functional as F
w = F.softmax(Q @ K.T / d**0.5, dim=-1)
out = w @ V
⚠️ Ограничения
  • \(O(n^2)\) по длине контекста → FlashAttention, sparse attention для длинных текстов.
  • Галлюцинации: генерирует правдоподобную чушь → RAG, grounding, fact-checking.
  • Стоимость: обучение GPT-3 ≈ $5M, инференс дорогой → дистилляция, квантование.
  • Positional encoding: фиксированный синус → ограниченная длина контекста (RoPE решает).
  • Токенизация: ≈4 символа на токен для русского → контекст расходуется быстрее.

Вопрос → эмбеддинг → поиск топ-5 статей → LLM собирает ответ по документам. 62% обращений без оператора, галлюцинации придушены цитированием.
